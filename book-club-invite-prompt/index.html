The book club invitation — the full prompt

This is the prompt behind the book club invitation from this week’s email — the cozy flyer, the RSVP form, and the live “Who’s coming” list. Fill in the brackets with your book club’s details, then paste the whole thing into your AI tool and let it build and host the page for you.

📚 You only need to fill in the brackets: your book, the host, the date, and the address (or “shared privately”). Everything else — design, RSVP form, live guest list — is already spelled out in the prompt.

EDIT THESE FIRST — replace every [BRACKET] before you paste: [BOOK CLUB NAME] — e.g. Neighborhood Book Club [BOOK TITLE] — e.g. A Redbird Christmas [AUTHOR] — e.g. Fannie Flagg [HOST NAME] — e.g. a neighbor's name [WEEKDAY, DATE] — e.g. Thursday, December 10 [TIME] — e.g. 7:00 PM [ADDRESS] — the host's address as plain text, or write "At the host's home — address shared privately" if the host doesn't want it on a public page [TEASER BULLETS] — 1–2 short bullets about the book to tempt readers: a one-line hook, and one question to ponder while reading. Keep it to two bullets, never a paragraph. [SEASON / THEME] — e.g. Christmas, fall, summer — this sets the emoji, the scene props, and the sparkle effect Step 1 — Build the invitation page: Build me a single, self-contained HTML page for my book club — a cozy invitation with working RSVPs, designed to be opened on phones from a texted link. No guest login or sign-up anywhere. Match this structure exactly: 1. THE FLYER CARD (top of page): - A rounded card (18px corners, soft warm shadow) on a cream background. - Header on a cream gradient: the club name in spaced evergreen capitals with wide letter-spacing, a thin gold rule under it, then the script headline "Join us this month for" in a flowing cursive, the book title very large in deep red serif, and "by [AUTHOR]" in italic serif underneath. - A cozy scene image under the header, with the ACTUAL book cover of [BOOK TITLE] front and center — on a table by a fireplace with a mug of cocoa and seasonal props to match [SEASON / THEME]. All lettering on the page is real text in web fonts — never bake words into the image; they go soft when people zoom. - A details block under the image: "Hosted by [HOST NAME]", then "[WEEKDAY, DATE] at [TIME]", then [ADDRESS], a gold ✦ ✦ ✦ divider, and one warm italic line inviting people to come discuss the book. 2. ACTION BUTTONS under the flyer: - One big red pill button: "🎄 Tap to RSVP" (swap the emoji to fit [SEASON / THEME]) that scrolls to the RSVP form. - Two smaller pill links beside each other: "📅 Add to Calendar" (a Google Calendar template link pre-filled with the club name, book, date and time) and "📍 Directions" (a Google Maps link to [ADDRESS] — leave it as a general Maps link if the address is private). 3. A "Something to ponder as you read" card with my [TEASER BULLETS]. 4. THE RSVP CARD, headed "RSVP here": - Eyebrow line with the club name, the heading "RSVP here", and a sub-line with the book title, date and time. - A form with: "Your name" text field; "Can you make it?" as two big tappable pills — "🎄 Count me in!" (fills evergreen green when selected) and "Can't make it" (fills soft red when selected); and "A note for the host (optional)" as a textarea. - A big red pill submit button: "Send my RSVP ❤️". - Friendly inline error messages if the name or the yes/no choice is missing — and if saving fails, tell the guest to text the host instead. Never fail silently. - After submitting, replace the form with a success state: "You're in, [first name]! 🎄" and "We've got your RSVP — see you [WEEKDAY, DATE] at [TIME]." (or "We'll miss you, [first name] ❤️" for a no), plus an "Update my RSVP" button that brings the form back. 5. A "WHO'S COMING" CARD under the RSVP, visible to everyone on the main page: - Three count boxes across the top: Coming / Can't make it / Responses. - Response cards, newest first: the guest's name in bold, a small tag pill on the right ("Coming" in an evergreen tint, "Can't make it" in soft red), and their note underneath when they wrote one. - A host view at the same link with ?host=1 that adds a "Hide from list" button to each response (two taps to confirm). Hiding removes it from everyone's view. Nothing is ever deleted. DESIGN SYSTEM (use these exactly): - Colors: cream background #faf3e7, paper cards #fffaf0, red #a52a21 (buttons), deep red #8c211a (title), evergreen #2f4a38, gold #b98a2f (rules and accents), ink #3d2c22, muted #7d6a5c, hairline borders #e6d7bd. - Fonts: Fraunces for headings and the book title, Great Vibes for the script headline, Jost for the club name and labels, Nunito Sans for body text. - Page width max 640px, centered, generous padding; rounded corners and soft shadows on every card; a gentle falling-snow (or seasonal sparkle) canvas behind everything, subtle and non-interactive. Step 2 — Make the RSVPs actually work (this is required, not decoration): - Save every RSVP to Firebase Firestore so the host and all guests share ONE live list. A version that only saves in the visitor's own browser is not acceptable for the real invitation. - One document per guest per event, tagged with an event key for this meeting, storing: name, attending (yes/no), note, and an updatedAt timestamp. - Remember each guest's document ID in their browser (localStorage) so when they come back they UPDATE their existing RSVP instead of creating a duplicate — prefill their name and note, and show their success state. - Listen for live updates (Firestore onSnapshot) filtered to this event, and re-render the counts and the Who's coming list automatically whenever anyone responds. - Escape guest names and notes when rendering them (never inject raw HTML from a form field). Step 3 — Host it and finish: - Deliver one HTML file (plus the scene image) that I can host free, e.g. on Vercel, at a public link with no sign-in wall for guests. - Set the share-preview (Open Graph) tags: title = club name + book title, description = "Join us this month for [BOOK TITLE] by [AUTHOR]. [WEEKDAY, DATE] at [TIME]. Tap to RSVP.", image = the flyer/scene image. - Test before you call it done: submit a test RSVP and watch it appear in Who's coming with the counts updated; submit again as the same guest and confirm it updates in place instead of duplicating; check it at phone width. One privacy note: this page is visible to anyone with the link. Only put the host's home address on it if the host is happy for every guest to have it that way — otherwise use the "address shared privately" wording and share the address by text.
